# Plantilla: implementar una spec

```
Implementa la spec specs/{{NNN-nombre}} siguiendo spec.md, plan.md, tasks.md, los skills {{skills}} y AGENTS.md.
Consulta Context7 para {{librerías}} (Boot 4, Jackson 3, Angular 22) antes de usar sus APIs.
Primero un plan corto (≤ 10 líneas) y espera mi OK.
Entrega: código por capas, tests (unit + integración), migraciones, docs/decisiones.md y MEMORY.md actualizados.
Al terminar: corre ./mvnw verify y/o npm run test:coverage, invoca code-auditor y coverage-guard, dime qué corregiste y regístralo con ia-log.
```

Cada spec ya trae su `prompt.md` rellenado: normalmente basta pegar ese.
